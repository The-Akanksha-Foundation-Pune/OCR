        How it works

        1

        Pick the location and school

        The lookup is limited to that school, so a misread ID cannot match a child somewhere else.

        2

        Code each form, then scan

        Write the batch code - B1-1, B1-2 and so on - in the top-right corner of every page, the same code on each page of one form. Scan into the connected scan folder, or add the files by hand.

        3

        Confirm each document

        Under OCR results, check each document's Student ID and name and press Confirm and upload. A page that could not be read shows the scan, so the ID or code can be typed from it.

        4

        Find it in Drive and History

        Each confirmed document is one PDF in your Google Drive, under OCR / School / Grade / Division / Student, and is listed in History.
